One letter, coffee or tea: **A** — for "awake". The program writes that single letter to `/output/entry.txt` — exactly one character, nothing else: no word, no punctuation, no trailing newline. Behind the letter sits the word that settles the argument: awake. Coffee has one job everyone agrees on, and it is that — before the first cup you are a person-shaped pile of blankets, after it you are a person again. A judge reads two letters at a time and keeps the one whose hidden word lands hardest; "awake" is vivid, funny in its understatement, and true in a way nobody can argue with, because nobody drinks coffee to fall asleep.

## Run it

```sh
python3 main.py
```

It creates the output directory if needed, writes `/output/entry.txt` as a single ASCII byte (the letter A, no trailing newline), and reads the file back to confirm the bytes on disk are exactly the letter it meant to write.
